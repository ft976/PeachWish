# 🎂 Bday03 - Interactive Birthday Greeting

A highly personalized, elegant, and beautifully animated birthday greeting website. This modern web application delivers a heartwarming cinematic text experience culminating in an interactive digital cake and a downloadable letter.

## ✨ Features

- **Interactive Sequence**: Engaging step-by-step animations triggered by user clicks (decorations, lights, balloons, cake).
- **Cinematic Typography**: Uses the gorgeous `Playfair Display` font for an elegant and highly legible experience.
- **Heartfelt Animated Letter**: A 77-line fully customized blessing and letter that fades in sequentially with a 4-second delay for a graceful read.
- **Hidden PDF Gift**: Reveals a smooth, CSS-styled floating "💌 Download Letter" button flawlessly overlaid after the final blessing ends, allowing a native download of the attached PDF note.
- **Fully Responsive Layout**: Implemented dynamic window sizing and CSS Media Queries to adapt perfectly across mobile, tablet, and desktop viewports.

## 🛠️ Technology Stack

- **HTML5 & CSS3**: Clean structured layout and highly customized UI styling.
- **JavaScript (jQuery)**: Powers the seamless animation timing, smooth fading transitions, and interactive sequence progression.
- **Less**: Advanced CSS preprocessing utilized for building the interactive digital 3D Cake.

## 🚀 Setup & Local Execution

To preview this interactive card locally:

1. Clone this repository: `git clone https://github.com/rehan9703/bday03.git`
2. Ensure you have a standard local dev server (like `http-server` via Node.js or Python's `http.server`).
3. Serve the current directory (for example): `npx http-server`
4. Open your web browser and view the magical sequence.

## 📂 Key Files

- `index.html`: The core framework and DOM container handling the greeting elements.
- `stylesheet.css`: Styling configurations, elegant typography layouts, and media queries.
- `effect.js`: Pure animation timelines spanning over 78 custom sequenced elements.
- `Letter_Farhat_Perfect.pdf`: The personal hidden message attached to the final presentation.
